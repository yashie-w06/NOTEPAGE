DOS-NOTE — offline HTML note editor

1. Keep index.html, style.css, and script.js together.
2. Double-click index.html to open it in Chrome, Firefox, or Edge.
3. Your work autosaves in that browser.
4. Use [S]ave HTML or Ctrl+S to download a standalone note with embedded images.
5. Use [O]pen or Ctrl+O to reopen an exported HTML note.

No installation, server, account, or internet connection is required.
